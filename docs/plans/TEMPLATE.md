# PLAN-N. Short imperative title

Copy to `plan-<n>-<slug>.md` with the next free number. Delete the guidance in
parentheses as you fill each section in.

## Goal

(One or two sentences. What is true when this is done that is not true now.
Write it so someone can check it without asking you.)

## Why now

(What changed, or what is blocked until this happens. If nothing changed and
nothing is blocked, this is not a plan yet.)

## Constraints

(What this plan may not break. Reference ADRs by number, for example: must not
change the append-only guarantee on the raw zone, per ADR-1.)

## Steps

1. (Small enough to finish in one sitting, and leaving the repo working.)
2. (No step should be "and then everything else".)

## Out of scope

(Named explicitly, so it does not get quietly pulled in.)

## Done when

- [ ] (Checkable conditions, not vibes.)

## Open questions

(Anything needing an answer before or during. If the answer turns out to be
architectural, move it into an ADR.)
