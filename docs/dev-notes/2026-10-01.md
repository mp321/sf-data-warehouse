# 2026-10-01

Billing audit across every GCP project on the account, and a forecast after
the 2026-09-30 apply. No code changed and nothing in the bucket or BigQuery
was touched.

## Scope

Measure what each project uses against the free tier and forecast when charges
start. Out of scope: changing the ingest cadence, which needs an ADR (see the
2026-09-30 follow-ups).

## Changes

- GCP, this project: enabled `cloudbilling.googleapis.com` and
  `billingbudgets.googleapis.com` to read billing linkage and budgets. Both are
  free. Disable with `gcloud services disable <api> --project=$GCP_PROJECT_ID`.
- This note.

## Findings

- **Internet egress is the binding free-tier limit, not storage.** Bytes GCS
  sent were about 100 GB in September against an always-free 100 GB/month, with
  `ingest.yml` red for 19 of those days. BigQuery is not the reader: on
  build Mondays GCS sent about 2 GB while BigQuery processed 24 GB.
- **The daily ingest run reads about 3x the raw zone over the network.**
  1.31 GB on 2026-10-01 against a 0.444 GB raw zone; 4.1 to 4.3 GB a day in
  early September at about 1.4 GB. Which step does the reading
  (`ingest.py`, `spatial.py` or `load.py`) is not measured.
- **Local sessions with `RAW_ZONE_URI` on the bucket are the other half.**
  33, 18, 12 and 5.5 GB on 09-07, 09-12, 09-29 and 09-30.
- Forecast at about $0.12/GB beyond 100 GB, with no local sessions:

  | Scenario | Oct | Nov | Dec |
  |---|---|---|---|
  | daily ingest, no apply | 128 GB, $3.41 | 280 GB, $21.62 | 450 GB, $42.01 |
  | daily ingest, weekly apply | 54 GB, $0 | 53 GB, $0 | 55 GB, $0 |
  | `ingest.yml` disabled | about 8 GB, $0 | same | same |

  A September-sized month of local sessions adds about 65 GB, so roughly $8
  more in the first row and about $2.20 in the second.
- Everything else is far inside the free tier: bucket 489 MB (5 GB free, crossed
  on 2026-12-19 only if never pruned), Class A about 2,800 and Class B about
  60,000 in September (5,000 and 50,000 free; the Class B overage is under a
  cent), BigQuery about 150 GB queried a month (1 TB free) and 26 MB stored,
  logging 23 MB (50 GiB free).
- Billing is enabled on two projects only: this one and an unrelated
  sandbox-era project with empty datasets, no buckets and no API traffic in
  six weeks.
- A $1 budget covers the whole billing account, alerting at 50, 90 and 100
  percent of actual spend. It has no forecasted-spend threshold.
- `cloudaicompanion` sees about 130 calls a day from the Data Agent Kit VS Code
  extension (`Code.GenerateCode`, all 200). Gemini in BigQuery code assist is
  documented as no additional cost; not confirmed against an invoice.
- `gs://<bucket>/sf/` holds a 3.2 MB copy of the export from 2026-08-15.
  The current-state table says the bucket holds only `published/`.
- `raw_datasf` still carries `defaultPartitionExpirationMs` of 60 days from the
  sandbox. PLAN-4 step 1 cleared only the table expiration.
