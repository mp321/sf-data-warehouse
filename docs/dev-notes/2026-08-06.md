pipeline.** Every session note since the PR #3 merge said the scheduled path

merge the cron ran a `main` with no spatial step and wrote to a runner's disk.

business locations across eight files into `gs://.../raw`, then the spatial
step.

**And it gave the bucket's derived zone a code stamp, which was the other
item.** `spatial.py` printed "the zone records no code version, so it was built
before the stamp existed" and rebuilt the whole zone: 523,339 rows in
`derived_point_h3`, 84,296 in `derived_polygon_h3`, 1,332,896 in
`derived_point_boundary`, 39,301 population cells and 24,000 pip-sample
answers. ADR-11's incremental half is keyed on per-partition row and file
counts and its stamp half on the source hash, and a zone with no stamp is a
full rebuild by definition, so this is the designed behaviour rather than a
surprise. The item had been written up the day before as "the first
credentialed thing to do" and needed nobody: it cost one 90 second step of a
run that was going to happen anyway.
